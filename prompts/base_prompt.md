# Ginyu Morandi Storybook Base Prompt


Create an original illustration of:

[SUBJECT]


## Visual Style

soft watercolor children's picture book illustration,

handmade paper texture,

gentle crayon grain,

warm and emotional atmosphere.


## Color Palette

Use:

- warm ivory background
- muted beige
- soft chestnut brown
- almond brown
- dusty pastel accents


Low saturation.

Morandi inspired colors.

Avoid:

- neon colors
- high contrast
- pure black


## Texture

Required:

- watercolor bleeding
- visible paper grain
- soft brush marks
- handmade imperfections


Avoid:

- 3D rendering
- glossy digital surfaces
- sharp vector style


## Composition

Layout:

- single main subject
- centered composition
- large negative space
- clean background


The subject should occupy:

20%-35% of the canvas.


## Character Design

Features:

- rounded shapes
- soft silhouette
- simple facial features
- gentle expression


Mood:

cute,
quiet,
warm,
healing.


## Typography

If text is needed:

Use handmade watercolor lettering.

Text style:

- soft brush writing
- imperfect edges
- children's storybook feeling


Avoid:

- modern digital fonts
- sharp typography


## Decorative Elements

Allowed:

- tiny hearts
- small flowers
- simple hand drawn symbols


Keep decorations minimal.


## Final Style Keywords

soft watercolor,

Morandi palette,

children's picture book,

handmade illustration,

warm ivory background,

gentle emotional design.
