# 🌰 Ginyu Morandi Storybook Skill

一个用于生成治愈系手绘插画的 AI 视觉风格 Skill。

## ✨ 风格特点

- 手绘水彩质感
- 蜡笔颗粒纹理
- 莫兰迪低饱和配色
- 儿童绘本插画感
- 温暖留白构图
- 柔和治愈氛围


## 🎨 视觉规则

核心关键词：

> soft watercolor  
> handmade paper texture  
> Morandi colors  
> children's picture book style


## 🐶 适用主题

可以生成：

- 动物角色
- OC角色
- 食物拟人
- 日常小物
- 表情贴纸


## 使用方式

输入任意主题，例如：

"一只戴花环的小猫"

Skill 会自动转换为：

温暖、柔和、手绘水彩绘本风。


## Design Philosophy

Soft.
Warm.
Simple.
Emotional.
