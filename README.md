# 🎨 Ginyu Morandi Storybook Skill

一个用于生成治愈系手绘插画的 AI Image Skill。

## Style Identity

核心视觉：

- 手绘水彩质感
- 蜡笔颗粒纹理
- 莫兰迪低饱和配色
- 柔和儿童绘本风格
- 大面积留白
- 轻盈治愈氛围


## Rules

生成任何主题时：

保持：

✅ 色彩体系  
✅ 插画质感  
✅ 构图规律  
✅ 留白比例  
✅ 手绘字体感觉  


不复制原始角色，
只继承视觉语言。


## Usage

输入：

"生成一只戴花环的小猫"


输出：

自动保持：

- Morandi palette
- watercolor texture
- storybook composition
